# micropython-waveshare-ESP32-S3-RLCD-4.2
Micropython based software for Waveshare's ESP32-S3-RLCD-4.2. Includes micropython driver for the ST7305 based 4.2 inch reflective LCD.



## Application Modules
The software contains the set of **apps** outlined below with screenshoots. These apps are simply micropython modules that provide an `app_init()`and an `app_end()` method.The apps are supported by a version of **tempos** so installing a new app is simply a matter of copying it into the **apps** directory.  A full decription of **tempos** can be found in the repository `jeffmer/TTGO-T-watch-2020-Micropython-OS`. Clicking the Waveshare units user button **key** cycles through the available apps.
